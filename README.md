# Pequeños Pasos

## Descripción

**Pequeños Pasos** es el prototipo de una aplicación móvil para una tienda de ropa y calzado infantil de 0 a 14 años.

El objetivo del proyecto es crear una interfaz sencilla, clara y fácil de utilizar, siguiendo las recomendaciones de **Material Design 3**.

El prototipo permite consultar productos, buscar prendas, seleccionar tallas, añadir productos al carrito y realizar un proceso de compra hasta llegar a la confirmación del pedido.

## Objetivos

Los principales objetivos del proyecto son:

- Diseñar una aplicación móvil de ropa infantil.
- Crear una navegación sencilla y fácil de entender.
- Utilizar componentes de Material Design 3.
- Crear un prototipo navegable en Figma.
- Realizar pruebas con usuarios para detectar posibles problemas.
- Aplicar mejoras al diseño después de las pruebas.

---

## Diseño

El diseño utiliza una interfaz limpia y sencilla, con colores claros y tonos azulados/turquesa como color principal.

Se han utilizado:

- Material Design 3.
- Diseño para Android Compact.
- Márgenes de 16 px.
- Espaciado basado en múltiplos de 8.
- Botones y elementos táctiles fáciles de utilizar.
- Tarjetas para mostrar los productos.
- Chips para los filtros.
- Barra de navegación inferior.
- Campos de texto.
- Snackbar.
- Bottom sheet para la guía de tallas.

También se han creado componentes propios para las tarjetas de producto y los selectores de talla.

---

## Pantallas

El prototipo cuenta con las siguientes pantallas principales:

1. **Inicio:** muestra las categorías y novedades.
2. **Catálogo:** permite consultar los productos y utilizar filtros.
3. **Detalle:** muestra la información de un producto y permite seleccionar una talla.
4. **Carrito:** muestra los productos seleccionados y el resumen del pedido.
5. **Checkout:** permite introducir los datos necesarios para realizar la compra.
6. **Confirmación:** muestra que el pedido se ha realizado correctamente.
7. **Perfil:** permite acceder a los datos y opciones del usuario.
